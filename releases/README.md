# SafeZone App Releases

## Download APK

Download the latest APK file to install and test the SafeZone app on your Android device.

### Latest Release
- **File**: `SafeZone.apk`
- **Location**: This folder

### Installation Instructions

1. Download the APK file from this folder
2. On your Android device, go to Settings > Security
3. Enable "Install from Unknown Sources" or "Install Unknown Apps"
4. Open the downloaded APK file
5. Follow the installation prompts
6. Grant necessary permissions when prompted

### Requirements
- Android 6.0 (API level 23) or higher
- Minimum 50MB free storage space

### Note
This is a test/development build. For production use, the app should be signed with a release key and distributed through official channels.
