# Screenshots Folder

Place your app screenshots here with the following naming convention:

- `screenshot1.png` - Login Screen
- `screenshot2.png` - Parent Dashboard
- `screenshot3.png` - Child Dashboard
- `screenshot4.png` - App Blocking
- `screenshot5.png` - Screen Time Settings
- `screenshot6.png` - Location Tracking
- `screenshot7.png` - Alerts
- `screenshot8.png` - Activity Logs

## Image Guidelines

- **Format**: PNG or JPG
- **Recommended Size**: 1080x2400 (or your device's native resolution)
- **File Size**: Keep under 500KB per image for faster loading
- **Naming**: Use lowercase with numbers (screenshot1.png, screenshot2.png, etc.)

The images will be automatically resized to 200px width in the README for a clean, compact display.
